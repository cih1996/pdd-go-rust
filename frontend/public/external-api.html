外部任务 API 说明 业务端统一入口

先在业务端后台配置好上游和平台账号，再到“系统核心配置”中开启“外部任务 API”。外部设备不直接调用适配器，只调用业务端这组接口。

调用顺序

  • 如需复用业务端“跳转链接模板路由”，先调用 GET /api/external/url-templates 拉取可用链接模板。
  • 先调用 POST /api/external/fetch-task 领取任务。
  • 如果返回 has_task = true，执行任务时可自行选一个模板链接打开，完成后调用 POST /api/external/submit-task 回传结果。
  • 截图直接放在 captures[].content_base64 里，服务端会自动生成文件名并上传，任务明细页可直接看到快照。

1. 获取跳转链接模板

GET /api/external/url-templates

{
  "success": true,
  "use_url_templates": true,
  "templates": [
    {
      "id": "urltpl_a",
      "name": "模板A",
      "template": "https://mobile.yangkeduo.com/order_checkout.html?goods_id=100&sku_id=200",
      "trigger_count": 12,
      "success_count": 9,
      "risk_count": 1
    }
  ]
}

返回的是业务端当前配置的跳转链接模板列表。你执行任务时如果用了其中某个链接，提交结果时把对应的 template_id 一并带回，业务端就会按原有 ADB 逻辑记录触发、成功、风控统计，并写入任务明细。

2. 领取任务

POST /api/external/fetch-task

{
  "worker_id": "cloud-001",
  "worker_name": "云手机-001",
  "source_code": "laoqian_worker"
}

字段说明：worker_id 必填，用于标识外部设备；worker_name 可选；source_code 可选，不填时由业务端自动选择可用账号和上游。

{
  "success": true,
  "has_task": true,
  "message": "ok",
  "task": {
    "task_id": "laoqian_worker_xxx",
    "upstream_task_ref": "749844241676087",
    "source_code": "laoqian_worker",
    "source_name": "老钱真实上游",
    "account_id": "acct_xxx",
    "account_name": "账号A",
    "task_items": [
      {
        "goods_id": "925751104085",
        "sku_id": "1874695437353",
        "source_url": "https://example.com/item",
        "step_index": 0
      }
    ]
  }
}
{
  "success": true,
  "has_task": false,
  "message": "当前暂无可领取任务",
  "task": null
}

3. 提交任务

POST /api/external/submit-task

{
  "task_id": "laoqian_worker_xxx",
  "worker_id": "cloud-001",
  "device_id": "cloud-001",
  "template_id": "urltpl_a",
  "result": "success",
  "message": "执行完成",
  "task_items": [
    {
      "goods_id": "925751104085",
      "sku_id": "1874695437353",
      "recognition": "success_image",
      "message": "命中成功图",
      "captures": [
        {
          "content_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
          "content_type": "image/png"
        }
      ]
    }
  ]
}

result 只支持 success、failure、cancelled。如果使用了跳转链接模板，请把 template_id 一并提交；图片文件名不用传，服务端会自动生成。

{
  "success": true,
  "message": "任务已提交",
  "task_id": "laoqian_worker_xxx",
  "device_id": "cloud-001",
  "detail_ids": ["detail_xxx"],
  "capture_urls": ["/api/captures/cap_xxx"]
}

注意事项

  • 重复任务会被业务端按现有业务键去重，避免多个外部设备或 ADB 设备重复执行同一任务。
  • 如果接口返回错误，错误信息会尽量透传到任务明细和提交日志里。
  • 若未传 device_id，业务端会默认使用 ext:<worker_id> 作为明细里的设备编号。
  • 若某个任务项的 recognition 明确回传 account_risk，业务端会把对应 template_id 记为一次风控。
